## Additional Information
- Event-Driven Programming - Event handler: Code is created and designed so that when an event occurs (clicks on buttons), the program will respond in a certain/specific way.
- Event-Driven Programming - Slots: Slots are functions (`on_add_contact` and `on remove_contact`) that are called in response to a signal or user events (mouse clicks).
- PySide6 widgets: `QMessageBox` was used in this activity to create a pop up message window that would appear to inform and ask the user to confirm an action.
